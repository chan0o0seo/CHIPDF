# 치pdf

PDF와 이미지 속 일본어를 인식하고, 한국어로 번역·편집하는 Windows·macOS 데스크톱 프로그램입니다.
문서 인식과 번역은 PC에서 처리하며, 원본 페이지 위에서 글자와 그림의 배치를 편집할 수 있습니다.
소스의 기본 번역 엔진은 Chrome 내장 번역입니다. 번역할 때 Chrome 보조 창에서 준비 버튼을 눌러 연결합니다.

## 주요 기능

- **문장 인식과 번역** — 원하는 문장을 사각형으로 선택해 일본어를 읽고 한국어로 번역합니다. 가로·세로 원문을 지원하며, 원문을 수정하거나 번역 후보를 비교해 적용할 수 있습니다.
- **텍스트 편집** — 글꼴, 크기, 색상, 부분 강조, 정렬과 문단 간격을 조절합니다. 홈 → 문단 또는 오른쪽 서식 패널에서 가로쓰기 상자 안의 위·가운데·아래 정렬을 선택합니다. 한국어 세로쓰기와 글꼴 즐겨찾기도 지원합니다.
- **원문 지우기와 배경 복원** — 문장 영역이나 브러시로 지정한 원문을 지우고, 도장 도구로 주변 배경을 복제합니다. 원본 비교로 편집 전 모습을 볼 수 있습니다.
- **이미지·도형과 배치** — 이미지와 도형을 추가하고 크기·회전·자르기·뒤집기를 조절합니다. 정렬, 간격 맞춤, 그룹, 앞뒤 순서와 잠금 기능을 제공합니다.
- **PDF 페이지 링크** — 원본 PDF의 내부 페이지 링크를 번역문에 이어 붙이거나, 텍스트 상자에 이동할 페이지를 직접 지정합니다.
- **여러 페이지 작업** — PDF와 이미지를 함께 열고 페이지별로 편집합니다. 왼쪽 페이지 목록을 끌거나 우클릭하여 순서를 바꿉니다. 여러 페이지를 함께 옮기고 실행 취소할 수 있으며 내부 링크도 유지합니다. 작업은 자동 저장되며, 원본과 편집 내용을 담은 `.twproj` 파일로 이어서 작업할 수 있습니다.
- **파일 끌어 놓기** — 시작 화면이나 편집 화면에 PDF·이미지 여러 개, 작업 파일 하나 또는 이미지 폴더 하나를 끌어 놓아 열 수 있습니다.
- **최근 작업** — 파일 메뉴의 `최근 작업 열기` 또는 시작 화면의 목록에서 최근 편집한 작업을 선택해 불러옵니다. 자동 저장본을 포함해 최대 12개를 보관하며, 파일 이름과 경로를 함께 표시합니다.
- **PDF·PNG 출력** — 전체·현재·선택한 페이지를 저장합니다. 새로 가져온 PDF는 원본 페이지의 배경·벡터·압축 이미지를 그대로 쓰고, 번역한 원문 텍스트는 PDF에서 지운 뒤 한국어를 실제 글자로 넣어 원본과 비슷한 용량을 유지합니다. 그림 속 원문을 지운 자리만 이미지로 덧입힙니다. 이미지 자료와 원본 PDF가 없는 이전 작업은 페이지 이미지로 출력합니다. 내부 페이지 링크는 페이지 순서와 출력 범위에 맞춰 저장합니다.

PDF 원본은 작업 파일 안에 한 번 보관하므로 외부 원본을 옮겨도 출력할 수 있습니다. 편집용 `.twproj`에는 미리보기·배경 복원 자료도 포함되므로 완성 PDF와 용량이 다릅니다. 기존 작업은 **PDF 원래 배경 적용**에서 작업에 사용한 원본 PDF를 선택하면, 유일하게 일치하는 페이지에 원본도 연결됩니다. 배경을 다시 만들어 원본과 픽셀이 달라진 작업도 선택한 PDF와 페이지 수가 같고 페이지마다 가로세로 비율이 같으면 같은 순서의 원본 페이지에 연결합니다. 이때 배경과 지우기 자료는 그대로 두고 인쇄 크기만 원본에 맞춥니다. 새 작업 파일 형식(버전 13)은 1.0.0 이상에서 열 수 있으며, 이전 형식은 계속 불러올 수 있습니다.

PDF 저장의 **한국어 글자** 선택에서 기본값 **글자로 넣기**는 지운 원문에 해당하는 PDF 텍스트를 실제로 삭제하고, 한국어를 글꼴과 함께 검색·복사 가능한 글자로 저장합니다. 글자의 대부분을 지우지 않은 원문은 남깁니다. 저장한 페이지가 편집 화면과 다르게 보이면(글꼴 없음·줄바꿈 차이 등) 그 페이지만 자동으로 글자를 이미지로 넣습니다. **이미지로 넣기**는 이전 방식으로, 원문을 시각적으로 가리고 원문 텍스트는 PDF 내부에 남습니다. 원본의 주석·양식·책갈피와 외부 링크는 복사하지 않습니다.

## Codex 번역 스킬 연결

자동화 기능을 포함해 새로 빌드한 배포본은 `--agent` 명령을 지원합니다. 기존 0.11.3 공개 실행 파일에는 이 기능이 없을 수 있습니다. 최신 Windows 설치 파일에서 기본 선택된 **Codex 번역 스킬 설치** 옵션을 유지하면 스킬 전체가 `%USERPROFILE%\.codex\skills\chipdf-ja-ko`에 자동으로 설치됩니다. `CODEX_HOME`을 지정한 사용자는 해당 폴더의 `skills` 아래에 설치됩니다. 앱을 제거해도 사용자 스킬은 보존됩니다. 이동식 버전이나 수동 설치는 배포본의 `skills/chipdf-ja-ko` 폴더 전체를 Codex 사용자 스킬 폴더에 복사합니다. 에이전트가 번역문을 작성하고 설치된 치pdf가 원문 인식·배경 복원·한국어 배치·PDF 출력을 담당합니다.

스킬은 일본어 PDF와 코코포리아 룸 ZIP을 지원합니다. 룸 JSON의 표시 문구와 이미지 문구를 함께 번역하며 명령·장면·자산 참조를 보존합니다. 웹에서 한국어 폰트 후보를 비교하고 실제 번역 미리보기로 크기·정렬을 검수한 기록을 남기는 절차도 포함합니다.

스킬의 `scripts/chipdf_agent.py`에서 `info`를 실행하면 Windows 설치 정보와 기본 설치 폴더에서 치pdf를 찾습니다. 설치 프로그램은 스킬 전체와 함께 실제 앱 위치를 `chipdf-install.ini`에 기록하므로 사용자 지정 설치 위치도 바로 연결됩니다. 이동식 버전은 현재 작업 폴더의 실행 파일·`latest-build.json`도 탐색하며, `--exe "실행 파일 경로" --remember info`로 한 번 연결하면 다른 작업 폴더에서도 찾습니다. 자동으로 찾았을 때는 `--remember info`로 경로를 저장할 수 있습니다. 런처는 Python 표준 라이브러리만 사용하며, Codex의 Python 런타임을 이용할 수 있습니다. PDF·OCR 의존성은 치pdf 배포본 내부 것을 사용합니다. 자세한 번역 절차는 스킬의 `SKILL.md`에 있습니다.

실행 파일을 직접 호출할 때는 `"Translation Studio.exe" --agent --result-json "결과.json" info` 형식을 사용합니다. 창 없는 실행 파일의 성공·실패 결과는 지정한 UTF-8 JSON 파일로 전달합니다. `prepare`, `apply`, `preview`, `export`를 지원하며 기존 편집기 실행 방법은 같습니다.

번역 결과를 마무리 편집할 때는 스킬 런처에서 `python chipdf_agent.py edit "한국어.twproj" --output "한국어_마무리.twproj"`를 실행합니다. 별도 편집본을 만들어 일반 치pdf 창에서 바로 엽니다. 이미 만든 편집본은 `--output` 없이 이어 열 수 있으며, 기존 파일을 덮어쓰는 복사는 허용하지 않습니다. 이 명령은 런처가 제공하므로 자동화 지원 앱의 재빌드 없이 사용할 수 있습니다. 텍스트 상자를 유지하려면 결과 PDF 대신 `.twproj`를 여세요. 편집 후 작업 저장(Ctrl+S)하고 저장한 편집본으로 `preview`와 `export`를 실행하면 최종 PDF로 이어집니다.

## 다운로드

Windows는 [1.0.0 릴리스](https://github.com/chan0o0seo/CHIPDF/releases/tag/ver_1.0.0), macOS는 [0.13.0 정식 릴리스](https://github.com/chan0o0seo/CHIPDF/releases/tag/ver_0.13.0)에서 받으세요. 배포 파일은 Windows 설치 파일과 macOS ZIP 두 개이며, 모두 OCR 자료와 LaMa 사진 복원 모델을 포함합니다.

| 환경 | 파일 |
| --- | --- |
| Windows 10 1809 이상·Windows 11, x64 | `chipdf-1.0.0.exe` |
| macOS 15 이상, Apple Silicon(M 시리즈)·Intel | `chipdf-0.13.0.zip` |

### Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-1.0.0.exe`를 실행합니다.
2. 안내에 따라 설치합니다. 기존 설치가 있다면 같은 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다. 설치 화면에서 바탕 화면 바로 가기도 선택할 수 있습니다.
4. Codex에서 일본어 PDF·코코포리아 룸을 번역하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다. 일반 편집기만 사용할 때는 해제해도 됩니다.

기존 `.twproj` 작업 파일, 자동 저장·백업, 개인 설정과 이미 설치된 오프라인 모델은 유지합니다. Python이나 OCR·LaMa 자료를 따로 설치할 필요가 없습니다.

### macOS 설치

1. `chipdf-0.13.0.zip`의 압축을 모두 풉니다.
2. ` → 이 Mac에 관하여`에서 칩/프로세서를 확인합니다.
3. M 시리즈이면 `Apple-Silicon`, Intel이면 `Intel` 폴더의 `ChiPDF.app`을 **응용 프로그램** 폴더로 옮깁니다.
4. `ChiPDF.app`을 실행합니다. ZIP 안의 `설치 안내.txt`에도 같은 안내가 들어 있습니다.

맥 앱은 Apple 배포 서명·공증을 받지 않았습니다. 신뢰하는 배포본이 차단된다면 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 실행을 확인합니다. 자세한 내용은 [macOS 안내](docs/macos.md)와 [Apple의 실행 안내](https://support.apple.com/102445)를 참고하세요.

### 처음 사용하기

1. 시작 화면에 PDF·이미지를 끌어 놓거나 **파일 → 열기**를 선택합니다. 이미지·PDF 여러 개, 이미지 폴더 하나 또는 `.twproj` 작업 파일 하나를 열 수 있습니다.
2. 문장을 사각형으로 선택해 원문을 읽습니다. 필요한 경우 세로 원문 인식을 선택합니다.
3. 한국어를 직접 입력하거나 **번역**을 누릅니다. Chrome 번역 도우미가 열리면 **번역 준비**를 누릅니다.
4. 원문을 지우고 글꼴·크기·색·정렬을 조절합니다. 브러시와 **사진 복원 · LaMa**로 이미지 배경도 복원할 수 있습니다.
5. **작업 저장**으로 `.twproj`를 보관하고 **내보내기**로 PDF·PNG를 만듭니다. 자동 저장본과 최근 작업 목록으로 이어서 편집할 수 있습니다.

## 1.0.0 변경 사항

- PDF 출력에서 번역한 원문이 PDF 텍스트이면 그 텍스트를 지우고, 그림 속 글자이면 배경에서 지운 자리만 이미지로 덧입힙니다. 한국어는 글꼴을 포함한 실제 글자로 넣어 원본 배경을 보존하면서 원본과 비슷한 용량을 유지합니다.
- 저장한 페이지를 편집 화면과 비교해 다르게 보이는 페이지는 글자를 이미지로 넣습니다. PDF 저장 창의 **한국어 글자**에서 이전 방식(이미지로 넣기)도 고를 수 있습니다.
- 자동화 `export`에 `--text-mode text|image`를 추가하고, 결과에 글자를 이미지로 넣은 페이지(`image_text_pages`)와 지운 원문 텍스트 수(`removed_source_text`)를 표시합니다.
- **PDF 원래 배경 적용**이 픽셀이 달라진 작업도 페이지 수와 비율이 같으면 같은 순서의 원본 페이지에 연결합니다.
- 글자 효과(외곽선·그림자·흐린 그림자·글자 배경·자간)를 넣었습니다. PDF로 저장해도 한국어는 실제 글자로 유지됩니다.
- 텍스트 상자의 글자와 배경 투명도를 따로 조절합니다. 그림은 밝기·대비·채도, 모서리 둥글게, 테두리를 조절합니다.
- 선택한 대상에 화면 크기가 일정한 조절점 8개와 회전 손잡이가 보이고, 마우스를 올리면 테두리가 표시됩니다.
- 캔버스 위쪽에 선택한 대상에 맞춰 바뀌는 서식 도구 막대를 넣었습니다. 텍스트는 글꼴·크기·글자색·굵게·기울임·밑줄·취소선·정렬·목록·간격·세로쓰기·투명도·효과·위치·서식 복사, 그림은 교체·자르기·뒤집기·조정·모양, 도형은 채우기·테두리·선 두께를 바로 고칩니다. 복제·삭제·잠금·순서·그룹은 끝의 더보기 메뉴에 있습니다.
- 글머리표·번호 목록을 넣었습니다(가로쓰기).
- 새로 만든 텍스트 상자는 입력할수록 옆으로 늘어나고, 상자 너비를 직접 조절하면 그 너비 안에서 줄이 바뀝니다. 줄이 넘칠 때 띄어쓰기가 아니라 넘친 음절에서 바로 줄을 바꾸는 '글자 단위로 줄내림'을 상자마다 고를 수 있습니다(새 상자 기본값). 기존 상자는 지금 줄바꿈을 그대로 유지합니다.
- 속성 패널에 슬라이더(끌면 바로 미리보기, 실행 취소는 한 번), 색 팔레트(문서 색·최근 색·기본 색·스포이트), 위치·크기 직접 입력, 정렬·간격·순서 버튼과 끌어서 순서를 바꾸는 **레이어** 탭을 추가했습니다.
- 작업 파일 형식이 13으로 바뀌었습니다. 1.0.0에서 저장한 작업 파일은 이전 버전에서 열 수 없습니다.

## 0.13.1 변경 사항

- 원본 유지 출력에서 수정 영역 주변에 가는 이중 경계선이 보이던 문제를 고쳤습니다. 원본과 같은 픽셀은 다시 그리지 않고, 맞닿은 수정 영역은 이미지 한 장으로 덧입힙니다.
- 원본 PDF가 없는 페이지를 이미지로 출력할 때 사진이 많은 페이지는 JPEG로 저장하고 ASCII85 인코딩을 쓰지 않아 용량을 크게 줄였습니다.
- 자동화 `export` 결과에 이미지로 출력한 페이지(`raster_pages`)와 원본 대비 용량(`size_ratio`)을 표시하고, Codex 스킬에 원본 PDF 연결을 유지하는 규칙을 추가했습니다.

## 0.13.0 변경 사항

- 원본 PDF의 글자·벡터·압축 이미지를 유지하고 수정 영역만 덧입혀 출력 PDF의 용량 증가를 줄입니다.
- 원본 PDF를 작업 파일 안에 한 번 보관하며, 기존 작업은 **PDF 원래 배경 적용**으로 원본을 연결할 수 있습니다.
- 새 작업 파일 형식 12는 0.13.0 이상에서 열 수 있습니다. 가려진 원문 텍스트는 출력 PDF 내부에 남을 수 있습니다.

### 이전 버전의 개선 사항

- 시작 화면·최근 작업 목록·페이지 목록·편집 캔버스에서 파일 끌어 놓기로 자료를 엽니다. 지원하지 않는 파일과 가져오기 중의 추가 드롭은 받지 않습니다.
- 맑은 고딕을 사용하는 일부 한글에서 획이 빠져 보이는 표시를 개선했습니다.
- 파일 기반 `--agent` 자동화와 Codex 번역 스킬을 배포본에 포함하고, Windows 설치에서 스킬을 함께 설치할 수 있습니다.
- macOS 다운로드 하나에 Apple Silicon·Intel용 앱과 설치 안내를 함께 제공합니다.

설치와 주요 기능은 [1.0.0 릴리스 안내](docs/releases/1.0.0.md), [0.13.1](docs/releases/0.13.1.md), [0.13.0](docs/releases/0.13.0.md) 안내에서도 볼 수 있습니다.

## 글씨 지우기와 사진 복원

`번역·지우기 → 브러시`에서 `글자만 선택` 또는 `칠한 부분 전체`를 고릅니다. 글자만 선택할 때는 사진의 글자를 **Alt+클릭**해 색을 고른 뒤 주변을 칠하세요. **Shift+드래그**는 선택을 뺍니다. 한 획을 마치면 빨간 표시가 실제로 지울 픽셀만 보여 줍니다. `지우기 설정`에서 글자색, 비슷한 색 포함 범위, 테두리 확장을 조절할 수 있습니다.

복원 방식은 `주변색 보간`(예전 사진 편집기의 주변색 보간·32회 평활화)과 `사진 복원 · LaMa`입니다. `지우기`를 누르면 현재 배경의 선택 영역만 바뀌며 기존 되돌리기·저장 기능을 사용합니다. 두 방식을 비교하려면 지운 직후 Ctrl+Z로 되돌린 뒤 같은 영역을 선택해 다른 방식을 적용하세요. PDF 원래 배경 자산을 사용할 수 있는 선택은 그 배경을 우선 사용합니다.

LaMa 배포판에는 모델과 실행 모듈이 포함되어 있어 별도 다운로드 없이 사용할 수 있습니다. 소스 실행 환경에서는 다음을 한 번 준비합니다. 기존 개발용 Python을 사용하세요.

```powershell
python -m pip install --target .deps -r requirements-inpaint.txt
python prepare_inpaint.py --download
python main.py
```

이미 모델을 받았다면 `python prepare_inpaint.py --from-file "C:\path\lama_fp32.onnx"`로 검증·복사하거나 `지우기 설정 → 파일 선택`으로 연결할 수 있습니다. 모델은 고정된 Carve/LaMa-ONNX FP32 512×512 배포본(208,044,816바이트)이며 크기와 SHA256을 확인합니다. 추론 중에는 다운로드나 외부 API 호출을 하지 않습니다. 모델 또는 실행 모듈이 없으면 이유를 표시하고 선택을 유지하며, 다른 엔진으로 자동 전환하지 않습니다.

LaMa를 포함한 실행 파일은 `python build_portable.py --with-inpaint`로 빌드합니다. 기본 경량 빌드는 LaMa 모델·ONNX Runtime을 제외하므로 모델 파일만 연결해서는 LaMa를 실행할 수 없습니다. 사용자 설정은 앱 데이터 폴더의 `brush-settings.json`에 저장됩니다.

사진 전체를 512픽셀로 축소하지 않고 원본 해상도의 부분 이미지를 겹쳐 처리합니다. 가려진 배경은 추정 결과이므로 사진과 선택 영역에 따라 복원 품질이 달라집니다.

## 소스 및 배포 관리

앱 소스(`studio/`, `main.py`), UI 아이콘(`assets/`), 설치·빌드 스크립트, 의존성 목록과 외부 구성 요소의 라이선스를 관리합니다. 테스트·QA·실험용 자료와 내부 보고서는 저장소에서 제외합니다. 설치 파일·ZIP·모델·로컬 작업 데이터는 Git에서 제외하며, 배포 파일은 [GitHub 릴리스](https://github.com/chan0o0seo/CHIPDF/releases)에 첨부합니다. 플랫폼별 배포 소스는 릴리스 노트에 표시하며, 현재 관리 소스는 `main` 브랜치에 있습니다. 외부 구성 요소의 라이선스는 [THIRD_PARTY.md](THIRD_PARTY.md)를 참고하세요.

Windows용 Python 3.12 환경에서 `python -m pip install --target .deps -r requirements-dev.txt`로 개발 의존성을 설치하고 `python prepare_assets.py`로 OCR 자료를 준비한 뒤 `python main.py`로 실행합니다. LaMa를 포함할 때는 위의 추가 런타임·모델 준비 절차를 먼저 실행하세요.

`python build_portable.py --with-inpaint`로 이동식 배포본을 만들고 `python build_installer.py`로 같은 버전의 설치 파일을 만듭니다. `Start Translation Studio.cmd`는 `dist`의 가장 최근 앱 빌드를 실행하므로 저장소에 개인별 빌드 경로를 기록하지 않습니다.

## 선택 오프라인 번역 팩

기본 배포는 약 1.25GB의 M2M100 가중치를 포함하지 않습니다. Chrome 번역을 사용하는 경우 기본 앱만 받으면 됩니다. Chrome 설치와 첫 언어팩 다운로드 용량은 별도입니다. 작은 오프라인 추론 라이브러리는 앱에 남겨 두어, 필요할 때 데이터 팩만 추가할 수 있습니다.

- 오프라인 번역이 필요하면 별도 `ChiPDF-M2M100-1.2B-Offline-Pack.zip`을 받은 뒤 `번역·지우기 → 오프라인 팩 → 오프라인 팩 설치`를 선택합니다.
- 이미 모델이 있다면 `기존 모델 폴더 연결`에서 `model.bin`과 `origin.json`이 들어 있는 폴더를 고릅니다. 이전 앱의 `_internal/vendor/m2m100-1.2b-int8`도 연결할 수 있으며 모델을 복사하지 않습니다.
- 설치한 팩은 `%LOCALAPPDATA%/TranslationStudio/offline-models`에 보관하고, 연결 정보는 같은 사용자 데이터 위치의 `offline-model.json`에 저장합니다. 앱 업데이트와 독립적으로 유지됩니다.
- 모델이 준비되면 `번역 설정·용어집`에서 오프라인 엔진을 선택하세요. Chrome를 다시 선택하면 앱이 로드했던 오프라인 모델을 해제합니다.
- 기본 배포에는 팩이 없지만, 기존 설치 위치에 있던 모델을 업데이트 중 자동 삭제하지 않습니다. 기존 모델 폴더를 외부에서 연결한 경우 그 폴더를 이동하거나 삭제하면 다시 연결해야 합니다.

개발용 생성 명령은 `python build_portable.py`(기본 경량판), `python build_model_pack.py`(별도 데이터 팩), `python build_installer.py`(설치 파일)입니다. 예전처럼 모델까지 묶으려면 `python build_portable.py --with-offline-model`을 사용합니다. 기본 자료 준비 명령 `python prepare_assets.py`는 번역 모델을 요구하지 않으며, 모델 출처 자료까지 갱신할 때만 `--offline-model`을 붙입니다.


## 번역 사용 방법

1. `번역·지우기 → 번역 설정·용어집`에서 Chrome 내장 번역 또는 기존 오프라인 엔진을 선택합니다. 설정은 작품마다 저장됩니다.
2. Chrome 엔진으로 번역을 누르면 번역 도우미가 열립니다. 도우미에서 `번역 준비`를 누르세요. 처음에는 Chrome가 일본어·한국어 언어팩을 준비합니다.
3. 도우미를 열어 둔 채 치pdf에서 문장을 번역합니다. 연결이 끊기면 `Chrome 연결`로 다시 열고 준비한 뒤 남은 문장을 번역하세요. 기존 번역문은 기본적으로 건너뜁니다.
4. 원문·번역 패널의 `화자·문맥·문단 입력`에서 줄 연결을 끄거나 번역에 사용할 입력을 확인할 수 있습니다. 다른 상자의 글은 자동으로 합치지 않습니다.
5. 작품 용어집에 권장 표기와 피할 표기를 등록하면 결과의 표기 문제를 표시합니다. `용어 표기 제안`은 교체 결과를 후보로 제시하므로 뜻·조사를 확인한 뒤 적용하세요.
6. `검토 완료`한 문장은 작품의 확정 번역에 저장됩니다. 같은 원문·화자·문맥에 재사용하고, 유사 원문은 `확정 번역에서 찾기`로 선택합니다. `다시 번역해 비교`는 재사용을 건너뛰고 새 번역을 요청합니다.

새로 가져온 PDF의 선택 가능한 텍스트를 작업 파일에 함께 보관합니다. 새 원문 영역을 읽을 때 해당 텍스트를 우선 활용하고, 불완전한 텍스트나 이미지 부분은 OCR로 처리합니다. 기존 프로젝트는 `PDF 원래 배경 적용`으로 원본 PDF를 다시 연결하면 일치하는 페이지의 텍스트 정보도 보관합니다. 직접 수정한 기존 원문을 자동으로 바꾸지 않습니다.

원문·번역 패널에서 원문 출처, 번역 출처, 숫자·용어·반복·일본어 잔존 등의 확인 안내를 제공합니다. 안내가 없더라도 번역 정확성을 보장하지 않습니다.

이 소스는 작업 형식 10으로 저장하며 이전 형식 1~9를 읽습니다. 새로 저장한 형식 10 파일은 이전 실행 파일에서 열리지 않을 수 있으므로 기존 저장본·백업을 보관하세요.
