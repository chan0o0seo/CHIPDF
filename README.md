# 치pdf · 0.9.0

PDF와 이미지 카드를 한 작품에 담아 한국어 텍스트를 직접 편집하는 Windows 데스크톱 앱입니다.
자체 창에서 실행하며 브라우저를 사용하지 않습니다.

일본어 문장을 사각형으로 선택하면 원문을 읽고 같은 자리에 빈 텍스트 상자를 만듭니다. 한국어를 직접 입력하거나 `번역`을 누르세요. `브러시`로 칠한 뒤 `지우기`를 누르면 해당 부분의 배경을 복원합니다. 인식과 번역은 PC에서 처리하며 문서를 외부로 보내지 않습니다.

**자동 번역에는 오역이 있습니다. 특히 단서·이름·부정 표현을 원문과 대조해야 합니다. 전체 PowerPoint 수준의 편집 도구는 개발 중입니다.**

## 실행

- 설치본은 `치pdf-0.9.0-Setup.exe`를 실행합니다. Windows 10 버전 1809(빌드 17763) 이상 또는 Windows 11의 64비트(x64) PC가 대상입니다. 관리자 권한 없이 현재 사용자 계정에 설치합니다. 설치 후 시작 메뉴의 `치pdf`로 실행합니다. 바탕 화면 바로 가기는 설치 중 선택할 수 있습니다.
- 개발 폴더에서는 `Start Translation Studio.cmd`를 더블클릭합니다.
- 이동식 배포 ZIP을 다른 위치에서 풀었다면 `Translation Studio/Translation Studio.exe`를 실행합니다. `_internal` 폴더도 함께 있어야 합니다.
- 별도 Python 설치가 필요하지 않습니다. `.twproj` 자동 파일 연결과 온라인 자동 업데이트는 후속 단계입니다. 현재 시험 배포본은 코드 서명되지 않았습니다.

0.9.0은 도장으로 배경을 복제하고, 실행 취소·다시 실행·원본 비교·원문 패널을 사용할 때 확대율과 보고 있던 위치를 유지합니다. 휠 버튼 드래그로 화면 이동과 글꼴 즐겨찾기도 포함합니다. 0.8.1의 PDF 실제 배경 보관 기능과 Windows 10 1809 이상의 설치 조건은 유지합니다. 이번 버전은 사용자 요청에 따라 테스트·실행 검증을 진행하지 않았습니다. 이전 Windows 지원 근거와 검증 범위는 [Windows 호환성](WINDOWS_COMPATIBILITY.ko.md)에 기록합니다.

## 설치·업데이트·제거

기본 설치 위치는 `%LOCALAPPDATA%/Programs/Translation Studio`입니다. 자동 저장·백업·개인 서식은 `%LOCALAPPDATA%/TranslationStudio`에 계속 보관합니다. 이동식 배포본에서 사용하던 개인 설정도 같은 Windows 계정이면 그대로 사용합니다. 직접 저장한 `.twproj`는 사용자가 선택한 위치에 남습니다.

업데이트할 때는 작업을 저장하고 실행 중인 편집기를 모두 닫은 뒤 새 설치 파일을 실행합니다. 기존 설치 위치와 바로 가기 선택을 이어받으며, 설치 위치를 바꾸거나 이전 버전으로 덮어쓰는 업데이트는 막습니다. 설치 위치를 옮기려면 먼저 프로그램을 제거한 뒤 새 위치에 설치합니다. 설치 과정에서 새로 문서를 변환하거나 번역하지 않습니다.

제거는 `Windows 설정 → 앱 → 설치된 앱 → 치pdf → 제거`에서 합니다. 프로그램과 바로 가기를 제거하고 작업 파일·자동 저장·백업·개인 서식은 보존합니다. 설치 폴더에 사용자가 직접 넣은 작업 파일도 지우지 않습니다. 안전하게 같은 폴더에 재설치할 수 있도록 작은 설치 식별 파일(`translation-studio.install.ini`)은 남습니다. 다시 설치한 뒤 작업을 열거나 시작 화면의 마지막 작업 이어서 열기를 사용하면 됩니다.

편집기가 실행 중이면 설치·제거를 중단하고 종료를 안내합니다. 작업을 강제로 닫거나 PC를 재시작하지 않습니다. 다른 파일이 들어 있는 임의의 폴더나 원본·설정 폴더 자체를 설치 대상으로 사용할 수 없으며, 비어 있는 프로그램 전용 폴더를 선택합니다.

## 작품 열기와 카드 전환

- `열기`에서 PDF·PNG·JPG·BMP를 여러 개 선택할 수 있습니다. 편집 화면에 여러 파일 또는 이미지 폴더 하나를 끌어 놓아도 됩니다.
- `파일 → 이미지 폴더 열기`는 해당 폴더 바로 안의 이미지를 숫자 순서로 가져옵니다. 하위 폴더는 포함하지 않습니다.
- 왼쪽 썸네일을 클릭하거나 Ctrl+PageUp/PageDown으로 카드를 바꿉니다. Ctrl/Shift 클릭으로 출력할 여러 장을 선택할 수 있습니다.
- `파일 → 자료 추가`로 열린 작품에 이미지·PDF를 더합니다. 추가도 한 번의 실행 취소로 되돌릴 수 있습니다.
- 한 작품에 최대 200장, 원본 이미지 합계 512MB를 담습니다. 가져오기를 중단하거나 파일 하나가 손상되면 기존 작품을 유지합니다.

PDF는 페이지별 원본 이미지와 글자를 제외한 실제 배경을 함께 가져옵니다. 일반 글자와 글자 모양으로 잘라 그린 색·이미지를 처리하며, 원래 배경 그림과 선을 보존합니다. 기본 200dpi이며 매우 큰 페이지는 한 변 6,000px·2,400만 픽셀 안으로 줄입니다. PDF의 페이지 방향과 인쇄 크기를 보존합니다. 편집에서는 카드와 같은 OCR·번역·배치를 사용합니다. 암호가 필요한 PDF는 잠금을 해제한 사본을 준비해야 합니다.

새로 가져온 자료는 `문장 선택` 도구로 시작하며 전체 페이지를 자동 인식하지 않습니다. 다른 카드로 이동하면 해당 페이지의 실행 중 처리를 중단하고, 늦게 온 결과가 다른 카드에 적용되지 않게 합니다. 기존 프로젝트도 열기만 해서는 OCR을 다시 시작하지 않습니다.

## 카드 편집하기

1. 왼쪽 목록에서 편집할 카드를 고릅니다.
2. `문장 선택`을 누르고 일본어 문장을 사각형으로 드래그합니다. 세로 일본어는 도구 옆에서 `세로 원문`을 고른 뒤 선택합니다. 읽은 일본어는 오른쪽 `원문 확인`에 표시하고, 선택한 자리에는 빈 입력 상자를 만듭니다. 한국어를 바로 입력하거나 `번역`을 누릅니다. 인식한 일본어는 `원문 수정`에서 고칠 수 있습니다. `＋ 삽입 → 텍스트`로 직접 상자를 추가할 수도 있습니다. 기존 상자는 더블클릭 또는 선택 후 Enter로 고칩니다.
3. Esc로 입력을 끝내면 상자를 드래그할 수 있습니다. 오른쪽 아래 손잡이는 크기, 위쪽 원은 회전입니다. Shift를 누르면 회전이 15도 간격에 맞춰집니다.
4. 글자를 선택해 글꼴·크기·색·굵게·기울임·밑줄·정렬을 적용합니다. 입력 중 일부 글자를 드래그 선택하면 그 부분에만 적용합니다.
5. `작업 저장`은 모든 카드의 원본과 편집 내용을 함께 담은 `.twproj` 파일을 만듭니다. `완성본 저장`에서 전체·현재·선택한 카드와 PNG·PDF 형식을 고릅니다.

확대한 화면은 **마우스 휠 버튼을 누른 채 드래그**해 상하좌우로 이동합니다. 선택·문장 선택·브러시·도장 도구에서 사용할 수 있고, 버튼을 놓으면 기존 도구로 돌아갑니다. 실행 취소·다시 실행, `원본 비교` 전환, `원문 확인` 패널을 열고 닫아도 확대율과 보고 있던 위치를 유지합니다.

글꼴 옆 **☆**를 누르면 현재 글꼴을 즐겨찾기에 추가하고, **★**를 다시 누르면 해제합니다. 옆의 **즐겨찾기** 또는 `서식 → 글꼴 즐겨찾기`에서 저장한 글꼴을 바로 적용합니다. 입력 중 선택한 일부 글자에도 적용할 수 있습니다. 목록의 `즐겨찾기에서 삭제`에서는 설치되지 않은 글꼴도 정리할 수 있습니다. 즐겨찾기는 `%LOCALAPPDATA%/TranslationStudio/font-favorites.json`에 저장하여 다른 작품과 다음 실행에서도 유지합니다.

PNG 한 장은 파일로, 여러 장은 선택한 위치 아래 새 폴더로 저장합니다. 파일 이름 앞에 원래 카드 번호를 넣어 순서를 유지합니다. PDF는 선택한 카드들을 원래 순서대로 한 문서에 담으며 카드의 인쇄 크기를 유지합니다. 이미지 카드의 인쇄 크기는 유효한 원본 DPI를 사용하고, 이전 작업에서 인쇄 크기가 없으면 200dpi를 기준으로 합니다.

출력 PDF에는 현재 카드 모습이 이미지로 들어갑니다. 글자를 다시 고칠 수 있는 파일은 `.twproj`입니다. PNG·PDF 묶음 출력은 끝난 뒤 결과를 확정하므로 중단해도 일부 페이지만 있는 폴더나 불완전한 PDF로 기존 출력을 바꾸지 않습니다.

직접 선택한 사각형 안의 일본어는 OCR 완료 직후 제거합니다. 분리된 PDF 글자가 있으면 실제 배경 픽셀을 그대로 사용하고 선·그림을 유지합니다. 아직 번역문이 비어 있어도 편집 화면과 완성본에 반영합니다. `원문 확인 → 원문 가리기`에서 상자별로 끄거나 켤 수 있고, 상자를 이동해도 지운 원문의 위치는 유지됩니다. 상자를 삭제하면 해당 상자의 원문 제거도 해제됩니다.

`브러시`에서는 지울 원본 부분을 칠하고 `지우기`를 누릅니다. 분홍색은 선택 표시이며, 버튼을 누르기 전에는 문서나 완성본이 바뀌지 않습니다. 브러시 크기는 도구 옆에서 조절하고, Esc 또는 `선택 취소`로 아직 적용하지 않은 선택을 버립니다. 한 번의 지우기는 Ctrl+Z로 되돌립니다. 원본 비교에서는 지우기 전 원본을 볼 수 있으며, 작업 저장·재열기·PNG/PDF 출력에 복원 결과를 보존합니다. 브러시는 원본 페이지에 적용하고 사용자가 추가한 글자·도형·이미지는 그대로 둡니다.

PDF 글자를 브러시로 칠한 경우에도 실제 배경을 사용해 글자 픽셀만 지웁니다. 같은 범위의 배경 그림·선은 유지합니다. 글자가 이미지에 합쳐진 자료나 안전하게 분리할 수 없는 PDF, PDF 글자가 없는 브러시 영역은 주변 픽셀 보간을 사용합니다. 이 경우 복잡한 그림이나 무늬에 흔적이 남을 수 있습니다. 사각형은 가로·세로 최소 24px, 한 번에 지우는 면적은 60만 픽셀까지입니다. `흰 배경`으로 상자 아래를 덮는 수동 기능도 있습니다.

`도장`은 선택한 배경 부분을 다른 위치에 복제하는 도구입니다. **Alt를 누른 채 복제할 지점을 클릭**한 뒤 칠할 위치에서 드래그합니다. 도구 옆에서 크기를 조절하며, 마우스 버튼을 놓을 때마다 한 획을 적용합니다. Ctrl+Z로 획 단위로 되돌릴 수 있습니다. 같은 카드에서는 도구 변경·원본 비교·실행 취소 후에도 복제 지점을 다시 사용할 수 있고, 다른 카드로 이동하면 지점을 새로 지정합니다. 현재 편집된 배경을 복제하며 추가한 텍스트·도형·이미지는 복제 대상에 포함하지 않습니다. 원본 비교에서는 편집 전 자료를 보고, 도장 결과는 작업 저장·재열기·PNG/PDF 출력에 포함됩니다.

0.8.0 이하에서 만든 작업은 `파일 → PDF 원래 배경 적용`에서 당시 사용한 원본 PDF를 선택합니다. 원본 이미지의 모든 픽셀이 일치하는 페이지만 연결하고 기존 원문 상자의 제거 배경을 갱신합니다. 번역문·위치·서식은 유지하며 Ctrl+Z로 되돌릴 수 있습니다. 이 메뉴는 기존 브러시 기록을 바꾸지 않습니다. 이후 저장한 작업에는 실제 배경이 포함되어 원본 PDF 없이 다른 PC에서도 편집할 수 있습니다.

`번역`은 선택한 문장만 처리합니다. 빈 상자는 바로 채우고 이미 입력한 글이 있으면 별도 후보를 보여 줍니다. `이 번역 적용`을 눌러야 기존 글이 바뀝니다. `파일 → 빈 번역문 모두 번역`으로 현재 페이지의 빈 상자를 함께 채울 수 있습니다. 원문이나 번역문을 고치는 중에 늦게 도착한 이전 번역은 적용하지 않습니다. 검토한 문장은 `검토 완료`로 표시할 수 있습니다.

`파일 → 페이지 자동 인식`과 `페이지 자동 인식 · 세로 원문`은 원하는 때에만 실행합니다. 기존 상자와 겹치는 영역은 추가하지 않고 기존 편집은 유지합니다. 자동 인식한 상자는 종전처럼 번역문을 채웠을 때 원문 획을 가립니다. 번역문의 쓰기 방향은 아래처럼 따로 선택합니다.

## 세로쓰기와 반복 작업

텍스트 상자를 선택하고 `서식 → 세로쓰기`를 켭니다. 글자는 위에서 아래로, 열은 오른쪽에서 왼쪽으로 흐릅니다. 같은 상자를 더블클릭해 한글을 입력하고, 마우스나 Shift+방향키로 일부 글자를 선택해 서식을 바꿉니다. 다시 끄면 가로쓰기로 돌아옵니다. 상자의 위치·크기와 원문 제거 영역은 유지합니다.

세로 입력 중 위·아래 방향키는 앞·뒤 글자로, 왼쪽·오른쪽은 옆 열로 이동합니다. 정렬 도구는 위쪽·가운데·아래쪽 정렬이 되고, 문단 줄 간격은 열 사이 간격이 됩니다. 글자가 넘치면 상자 아래에 표시하므로 손잡이로 너비나 높이를 늘립니다. 저장·재열기·그룹 변형·PNG/PDF 출력도 같은 세로 배치를 사용합니다.

영문과 숫자는 한 글자씩 똑바로 세웁니다. 괄호·긴 대시·일본어 장음은 돌리고 일본어 쉼표·마침표는 오른쪽 위에 배치합니다. 일본어 출판용 금칙 처리, 루비와 가로 숫자 묶음(세로 안의 가로쓰기)은 아직 지원하지 않습니다.

- **글자 서식 저장:** 상자 하나를 선택해 `서식 → 글자 서식 저장`에 이름을 붙입니다. 첫 글자의 글꼴·크기·색·강조와 첫 문단의 정렬·간격, 상자 여백·쓰기 방향을 저장합니다. `저장한 글자 서식 적용`은 선택한 상자 전체에 적용하므로 부분 서식도 통일됩니다. 문구·원문·검토 상태와 상자 배경은 유지합니다.
- **글상자 배치 저장:** `배치 → 이 카드의 글상자 배치 저장`으로 텍스트 위치·크기·회전·배율을 저장합니다. `저장한 글상자 배치 적용`에서 대상 카드와 문구별 이동 위치를 확인하고 적용합니다. 같은 픽셀 크기와 같은 수의 텍스트 상자가 필요하며, 그룹 안 글자나 잠긴 글자가 있는 카드는 제외합니다.
- **배치 대응 순서:** 보이는 상자 기준으로 위에서 아래, 같은 높이에서는 왼쪽에서 오른쪽 순서입니다. 카드마다 문구의 위치가 다르면 적용 창의 대응 목록을 먼저 확인합니다. 기본은 배치만 바꾸고, 체크하면 저장한 글자 서식도 함께 적용합니다. 각 카드의 문구·원문 제거 영역·검토 상태·도형·이미지는 유지하며 여러 장의 변경을 한 번에 실행 취소할 수 있습니다.

이름 붙인 서식과 배치는 `%LOCALAPPDATA%/TranslationStudio/presets.json`에 보관해 다른 작품과 다음 실행에서도 사용합니다. `.twproj`에는 적용된 편집 결과가 저장되며 개인 서식 목록은 포함하지 않습니다.

## 도형·이미지와 배치

`＋ 삽입`에서 텍스트, 사각형, 둥근 사각형, 타원·원, 선, 화살표, 이미지를 추가합니다. 이미지 선택 시에는 자르기·교체·뒤집기 도구가, 도형 선택 시에는 채우기·테두리·선 두께가 나타납니다. 선택이 없으면 상세 도구를 접습니다.

- **이미지:** 기본은 비율 고정입니다. 자르기에서는 남길 부분을 드래그하고 적용합니다. 원래 이미지가 작업 안에 보존되므로 전체로 되돌릴 수 있습니다. 교체도 실행 취소할 수 있으며, 삽입했던 외부 이미지 파일이 없어져도 프로젝트는 열립니다.
- **정렬:** 여러 대상을 선택해 `배치`에서 위치를 맞춥니다. 하나만 선택하면 페이지에 맞춥니다. 같은 간격은 세 개 이상을 선택하면 사용할 수 있으며 양 끝 대상은 유지합니다. 회전한 대상의 보이는 상자 범위를 기준으로 계산합니다.
- **순서·잠금:** `배치`에서 맨 앞으로·뒤로, 한 단계 이동, 잠금을 선택합니다. 잠긴 대상은 이동·서식·삭제·자동 번역에서 보호합니다. 잠긴 대상을 선택해 해제하거나 `모두 잠금 해제`를 사용합니다. 혼합 선택에 잠긴 대상이 있으면 배치 변경을 막습니다.
- **복사·붙여넣기:** 텍스트·도형·이미지를 함께 복사할 수 있습니다. 다른 원본 카드에 붙이면 번역문과 서식·그림은 가져오고 이전 카드의 원문 제거 기록은 가져오지 않습니다. 글자 입력 중에는 문장 복사·붙여넣기로 동작합니다.
- **글자 서식:** `서식` 메뉴에 취소선, 대표 글자 서식 복사·붙여넣기가 있습니다. `배치 → 위치·크기`에서 좌표, 크기, 회전, 불투명도를 숫자로 조절할 수 있습니다.
- **그룹:** 여러 대상을 선택해 `배치 → 그룹` 또는 Ctrl+G로 묶습니다. 한 번에 이동·비율 유지 크기 조절·회전·복사할 수 있습니다. 더블클릭하면 안쪽 요소를 편집하고, Esc 또는 `그룹 편집 끝내기`로 나옵니다. 글자 입력 중 Esc는 입력을 먼저 끝냅니다. Ctrl+Shift+G로 해제하며 배치·글자 크기를 유지합니다. 그룹 안의 그룹도 8단계까지 지원합니다.
- **맞춤 안내선:** 드래그할 때 현재 편집 범위의 다른 대상과 페이지의 가장자리·가운데에 맞춥니다. Alt를 누르면 자유롭게 이동하며 `배치 → 안내선에 맞춤`에서 끌 수 있습니다. 안내선은 완성본에 나오지 않습니다.
- **문단:** 텍스트 선택 후 `서식 → 문단 간격·여백`에서 줄 간격, 문단 앞·뒤 간격, 안쪽 여백을 조절합니다. 선택한 상자의 모든 문단에 적용하며 부분 글자 서식은 유지합니다. 그룹 안에서 하나를 정렬하면 해당 그룹을 기준으로 맞춥니다.

이미지는 한 변 12,000px·총 2,400만 픽셀, PNG 변환 후 약 9MB까지 삽입할 수 있습니다. 작업의 이미지·편집 정보는 64MB까지 지원합니다. 현재 자르기는 사각형이며, 자유형 도형은 아직 없습니다.

| 조작 | 방법 |
|---|---|
| 여러 상자 선택 | Shift 클릭 또는 빈 곳에서 드래그 |
| 이동 | 상자 선택 후 방향키, Shift+방향키는 10px |
| 실행 취소·다시 실행 | Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z |
| 상자 복제·삭제 | Ctrl+D / Delete |
| 복사·잘라내기·붙여넣기 | Ctrl+C / Ctrl+X / Ctrl+V |
| 전체 선택 / 잠금 전환 | Ctrl+A / Ctrl+L |
| 그룹 / 그룹 해제 | Ctrl+G / Ctrl+Shift+G |
| 그룹 안 편집 / 끝내기 | 그룹 더블클릭 / Esc |
| 안내선에 맞추지 않고 드래그 | Alt+드래그 |
| 이전 카드 / 다음 카드 | Ctrl+PageUp / Ctrl+PageDown |
| 텍스트 / 이미지 삽입 | Ctrl+T / Ctrl+Shift+I |
| 확대·축소 | Ctrl+마우스 휠, 하단 버튼 |
| 화면 이동 | 마우스 휠 버튼을 누른 채 드래그 |
| 도장 복제 지점 지정 / 칠하기 | 도장에서 Alt+클릭 / 드래그 |
| 원본 보기 | `원본 비교`를 켜고 다시 눌러 편집 화면으로 복귀 |

입력 중 방향키와 Ctrl+Z는 글자 편집에 적용됩니다. Esc로 입력을 끝낸 뒤에는 상자 편집에 적용됩니다.

## 저장과 복구

변경 후 자동 저장합니다. 처음 연 카드는 `%LOCALAPPDATA%/TranslationStudio/recovery`에 저장하며 시작 화면의 `마지막 작업 이어서 열기`로 복원할 수 있습니다. `작업 저장`으로 보관 위치를 정하면 이후 변경은 그 프로젝트에 자동 저장됩니다.

직전 정상 저장본은 `.twproj.bak`로 보존합니다. 열기 창에서 이 파일을 선택한 뒤 새 `.twproj`로 저장할 수 있습니다. 저장 실패는 하단에 표시하며, 실패한 상태에서 종료할 때만 확인합니다.

0.1~0.8.1 작업도 열 수 있습니다. 0.9.0은 0.8.1과 같은 버전 8 형식으로 원본·PDF의 실제 배경·편집 내용을 저장합니다. 기존 작업을 열기만 하면 파일을 바꾸지 않습니다. 이전 형식의 작업을 편집하거나 저장하면 버전 8로 저장되고 직전 저장본을 백업합니다. 0.8.0 이하 앱은 버전 8 작업을 열 수 없으므로 계속 이전 앱을 사용할 작업은 다른 이름으로 저장해 주세요. 원본과 실제 배경의 합계는 작품당 512MB까지입니다.

원본은 프로젝트 안에 사본으로 보관하므로 원본 파일을 옮겨도 다시 열 수 있습니다. 새로 가져온 자료의 원래 파일 경로도 보존해 다른 카드의 원본에 출력을 덮어쓰지 않게 합니다. 이미지 카드 한 장은 한 변 16,000px·총 8천만 픽셀까지 지원합니다. 페이지를 넘겨도 편집 내용과 실행 취소 기록을 유지하며, 실행 취소하면 해당 편집을 했던 카드로 돌아갑니다.

## 개발

Windows x64 / Python 3.12, PySide6 Essentials 6.10.2. 다음 명령은 이 폴더에서 실행합니다. 일반 사용자는 배포본을 실행하면 되며, 아래 모델 다운로드·변환 과정은 개발자용입니다.

```powershell
python -m pip install --target .deps -r requirements-dev.txt
python -m pip install --target .convert-deps -r requirements-convert.txt
python prepare_m2m.py
python prepare_assets.py
python main.py
python -m unittest test_studio.StudioTests test_workflow.WorkflowTests test_editing.EditingTests test_layout.LayoutTests test_collection.CollectionTests test_vertical_layout.VerticalLayoutTests test_vertical_editor.VerticalEditorTests test_presets.PresetTests test_runtime test_installer test_manual_regions test_manual_editor.ManualEditorTests test_pdf_background test_pdf_background_storage test_pdf_text_stream test_pdf_repair -v
python verify_manual.py
python qa_vertical.py
python build_portable.py
python verify_portable.py
python prepare_installer.py
python build_installer.py
```

테스트·개발용 저장 위치는 `python main.py --data-dir ./dev-data`로 분리할 수 있습니다. 빌드는 기존 릴리스를 지우지 않고 `dist/<빌드 ID>`에 생성합니다. 기존 `../pdf_localizer`를 실행 시 참조하지 않습니다.

GitHub에는 소스·테스트·설정·`assets`·문서·`vendor/notices`를 보관합니다. `.gitignore`가 실행 파일, 모델, 의존성과 QA 결과를 이미 제외하므로 업로드를 위해 로컬 파일을 삭제할 필요는 없습니다. 설치 파일과 배포 ZIP은 별도로 백업하거나 GitHub Releases에 보관하세요.

새로 복제한 폴더에서는 위 명령으로 의존성과 모델을 준비합니다. 이미 `vendor/m2m100-int8`에 변환된 모델이 있으면 `.convert-deps` 설치와 `prepare_m2m.py` 실행을 생략할 수 있습니다. `.engine-deps`는 선택적인 엔진 실험용이며 프로그램 실행에 필요하지 않습니다. `__pycache__`와 `.build`는 실행·빌드할 때 다시 만들어집니다. 과거 `qa` 기록은 삭제하면 자동으로 되살아나지 않습니다. 이전 0.8.1 배포본 복구를 위해 만든 `python verify_recovery.py`는 과거 QA 자료 없이 OCR·번역·PDF 배경과 저장·재열기를 확인하는 개발 도구입니다.

설치 제작 도구는 고정된 Inno Setup 7.1.0을 SHA-256와 배포자 서명 확인 후 `.build-tools` 안에 이동식으로 준비합니다. 일반 사용자의 컴퓨터에는 이 개발 도구를 설치하지 않습니다. 설치 검증은 `build_installer.py --qa-token <별도 식별자>`로 만든 두 버전과 `verify_installer.py --previous-metadata <이전 installer-qa.json> --current-metadata <현재 installer-qa.json>`을 사용합니다. 검증 도구는 실제 사용자용 AppId 설치 파일을 거절하며 시험용 등록·바로 가기·프로젝트를 분리합니다.
