# 완성본과 편집본 전달

최종 검수를 마친 뒤 다음 두 묶음을 새 경로에 만들고, 응답에 두 ZIP의 절대 경로 링크를 각각 표시한다. 사용자가 다른 전달 형식을 명시하면 그 요청을 우선한다.

- `<작업명>_완성본.zip`: 바로 사용할 최종 한국어 PDF·이미지 또는 가져오기용 코코포리아 룸 ZIP을 담는다. 보고서·임시 미리보기·번역 전 프로젝트는 넣지 않는다. 코코포리아의 가져오기용 ZIP 자체는 기존 루트 구조를 유지하며, 바깥 전달용 ZIP에서 꺼내 가져오도록 안내한다.
- `<작업명>_ChiPDF편집본.zip`: 완성본을 출력한 최종 `.twproj`를 모두 담는다. 글자·이미지·페이지 순서와 서식을 ChiPDF에서 계속 편집할 수 있어야 한다. 룸 작업은 번역 이미지에 대응하는 모든 프로젝트와 페이지↔자산 대응표를 포함하고, JSON 번역표·검수 기록 등 후속 수정에 필요한 자료도 이 묶음에 보관한다. 편집할 이미지가 없는 룸은 그 사실을 명시하고 실제 문구 수정 자료를 전달하며, 불필요한 `.twproj`를 만들지 않는다.

완성본과 편집본은 같은 최종 저장 상태를 기준으로 한다. 최종 수정 후 `.twproj`를 저장하고 그 파일에서 다시 출력·검수한 뒤 묶는다. 각 묶음에 여러 파일이 있으면 충돌 없는 상대 경로를 사용하고, 개인 실행 경로·연결 설정·캐시·자동 백업은 제외한다. 편집에 필요한 외부 글꼴은 재배포가 허용될 때만 라이선스와 함께 포함하고, 포함할 수 없으면 글꼴 이름과 공식 다운로드 위치를 편집본 안내에 적는다.

ZIP을 만든 뒤 CRC 검사를 실행하고, 압축을 별도 임시 폴더에 풀어 최종 PDF/이미지와 `.twproj`가 열리는지 확인한다. 편집본의 페이지 수·순서·텍스트 상자와 이미지가 최종 상태와 일치하는지 확인한다. 룸 작업은 자산 대응표의 프로젝트·페이지가 실제로 들어 있는지도 대조한다. 검수하지 못한 범위는 완료로 표시하지 않는다.

최종 응답에는 **완성본 묶음**, **ChiPDF 편집본 묶음** 링크와 여는 방법·구체적인 미완료 항목만 간단히 적는다. 필요하면 최종 PDF나 가져오기용 룸 ZIP의 개별 링크도 추가한다.
