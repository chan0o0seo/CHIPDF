치pdf 0.13.0 · macOS 설치 안내

지원 환경: macOS 15 이상, Apple Silicon(M 시리즈) 또는 Intel Mac

1. chipdf-0.13.0.zip의 압축을 모두 풉니다.
2. Apple 메뉴 → 이 Mac에 관하여에서 칩/프로세서를 확인합니다.
3. Apple Silicon(M 시리즈)이면 Apple-Silicon 폴더를,
   Intel 프로세서이면 Intel 폴더를 엽니다.
4. 선택한 폴더의 ChiPDF.app을 응용 프로그램 폴더로 옮깁니다.
5. ChiPDF.app을 실행합니다.

앱은 Apple 배포 서명·공증을 받지 않았습니다. 신뢰하는 배포본인데
macOS가 차단한다면 한 번 실행을 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안의
보안 항목에서 '그래도 열기'를 선택하고 안내에 따라 확인합니다.
Apple 안내: https://support.apple.com/102445

시작 화면 또는 편집 화면에 PDF, PNG/JPG/JPEG/BMP 이미지,
.twproj 작업 파일 하나 또는 이미지 폴더 하나를 끌어 놓아 열 수 있습니다.
파일 메뉴의 열기로도 같은 자료를 불러올 수 있습니다.

문장을 사각형으로 선택해 원문을 읽고 한국어를 입력하거나 번역합니다.
Chrome 번역을 사용할 때는 번역 도우미 창에서 '번역 준비'를 누릅니다.
텍스트의 글꼴·크기·색·정렬을 편집하고, 원문 지우기와 LaMa 배경 복원을 사용할 수 있습니다.
작업 파일(.twproj)로 저장한 뒤 PDF 또는 PNG로 내보냅니다.

작업 파일 형식은 Windows와 같습니다. 다른 운영체제에 없는 글꼴은
대체될 수 있으므로 줄바꿈과 배치를 확인하세요.

새로 저장한 작업 파일(형식 12)은 치pdf 0.13.0 이상에서 열어 주세요.
새로 가져온 PDF는 원본을 보관하고 수정 영역만 덧입혀 출력합니다.
가려진 원문 텍스트는 출력 PDF 내부에 남아 검색·복사에 포함될 수 있습니다.
