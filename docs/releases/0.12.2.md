# 치pdf 0.12.2

PDF 페이지 순서 변경과 텍스트 상자 안의 세로 정렬을 추가하고, 오른쪽 속성 패널이 잘리는 문제를 수정했습니다. 0.12.0 이후 변경 사항을 모두 포함합니다.

## 다운로드

| 운영체제 | 파일 | 지원 환경 |
| --- | --- | --- |
| Windows | [chipdf-0.12.2.exe](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.12.2/chipdf-0.12.2.exe) | Windows 10 1809 이상·Windows 11, x64 |
| macOS | [chipdf-0.12.2.zip](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.12.2/chipdf-0.12.2.zip) | macOS 15 이상, Apple Silicon·Intel |

두 배포본 모두 일본어 OCR 자료와 LaMa 사진 복원 모델·실행 모듈을 포함합니다. Python이나 모델을 따로 설치할 필요가 없습니다. 기본 번역 엔진은 Chrome 내장 번역이며, 별도의 M2M100 오프라인 번역 모델은 포함하지 않습니다.

## 변경 사항

- **PDF 페이지 순서 변경:** 왼쪽 페이지 목록을 끌어서 옮기거나 우클릭 메뉴에서 한 페이지 앞뒤·지정 위치로 이동합니다. Ctrl/Shift로 여러 페이지를 함께 선택할 수 있습니다. 실행 취소·다시 실행과 저장을 지원하며 내부 페이지 링크도 유지합니다.
- **상자 안 글자 세로 정렬:** 가로쓰기 텍스트 상자를 선택하고 **홈 → 문단** 또는 **오른쪽 속성 → 서식 → 문단**에서 위·세로 가운데·아래 정렬을 선택합니다. 문단의 왼쪽·가운데·오른쪽 정렬과 함께 적용되며 PDF·PNG 출력에도 반영됩니다. 두 위치의 설정 값은 함께 갱신됩니다. 세로쓰기는 기존 문단 정렬을 사용합니다.
- **속성 패널 잘림 수정:** 글자 서식 버튼을 두 줄로 배치하고, 좁은 패널에서는 입력란이 다음 줄로 내려가도록 수정했습니다. 긴 내용은 세로로 스크롤하며 확인할 수 있습니다.
- **Codex 스킬 전달 방식 개선:** 작업 종료 후 완성본 ZIP과 마지막 출력에 사용한 최종 `.twproj` 편집본 ZIP을 각각 전달하도록 지침을 업데이트했습니다. 코코포리아 룸 작업도 같은 기준을 적용합니다.

## Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-0.12.2.exe`를 실행합니다.
2. 설치 안내를 따릅니다. 이미 설치했다면 기존 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다.
4. 새 스킬도 적용하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다.

기존 작업 파일, 자동 저장·백업, 개인 서식과 이미 설치된 오프라인 모델은 유지합니다.

## macOS 설치

1. `chipdf-0.12.2.zip`의 압축을 모두 풉니다.
2. ** → 이 Mac에 관하여**에서 칩/프로세서를 확인합니다.
3. M 시리즈이면 `Apple-Silicon`, Intel이면 `Intel` 폴더를 엽니다.
4. 해당 폴더의 `ChiPDF.app`을 **응용 프로그램** 폴더로 옮기고 실행합니다.

ZIP 안의 `설치 안내.txt`에도 안내가 있습니다. 맥 앱은 Apple 배포 서명·공증을 받지 않았습니다. 신뢰하는 배포본이 차단된다면 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 실행을 확인합니다.

## 작업 파일과 검증

이전 형식 1~10의 작업 파일을 읽습니다. 새로 저장한 작업 파일은 형식 11을 사용하므로 **치pdf 0.12.1 이상**에서 열어 주세요. Windows와 macOS 사이에 없는 글꼴은 대체될 수 있으므로 줄바꿈과 배치를 확인하세요.

Windows 배포본에 포함된 코드로 29개 테스트와 실행 파일의 시작 화면을 확인했습니다. 페이지 순서·내부 링크·저장·실행 취소, 글자 정렬·한글 입력, 홈/속성 패널 설정 동기화, 좁은 패널과 큰 글꼴에서의 입력란 배치를 검사했습니다.

자세한 기능은 [README](https://github.com/chan0o0seo/CHIPDF#readme), 소스는 [0.12.2 소스](https://github.com/chan0o0seo/CHIPDF/tree/ver_0.12.2)를 참고하세요.
