# 치pdf 0.11.3

글자 크기 조절 화살표와 최근 작업 불러오기를 개선하고, Windows·macOS에서 LaMa 사진 복원을 사용할 수 있는 버전입니다.

## 변경 사항

- 글자 크기 등 숫자 입력칸의 위·아래 화살표를 테마에 맞는 아이콘으로 표시합니다. 값과 단위가 잘리지 않도록 입력칸 폭도 조정했습니다.
- 파일 메뉴의 **최근 작업 열기**와 시작 화면의 **최근 편집한 작업** 목록에서 원하는 파일을 불러올 수 있습니다.
- 최근 작업은 자동 저장본을 포함해 최대 12개를 기억합니다. 이름과 경로를 함께 표시하고, 삭제되거나 이동한 파일은 비활성화합니다.
- 이전 버전의 마지막 작업 기록을 이어받습니다. 자동 저장본을 별도 작업 파일로 저장하면 목록도 해당 파일로 갱신합니다.
- 작은 창에서는 시작 화면을 스크롤할 수 있습니다.
- 복원 방식의 **이전 방식**을 **주변색 보간**으로 이름을 바꿨습니다.
- 글자색 기반 브러시 선택, Alt+클릭 색 추출, Shift+드래그 선택 빼기, 지울 부분 미리보기와 LaMa 복원을 포함합니다.
- macOS 15 이상에서 Apple Silicon과 Intel용 앱을 제공합니다.
- 작업 파일 형식은 **10**으로 유지합니다.

## 설치 및 실행

- `ChiPDF-0.11.3-LaMa-Setup.exe`: Windows 설치 파일입니다.
- `ChiPDF-0.11.3-LaMa-Windows.zip`: 모두 압축을 푼 뒤 `Translation Studio/Translation Studio.exe`를 실행하세요.
- `ChiPDF-0.11.3-macOS-arm64-LaMa.zip`: Apple Silicon(M 시리즈) 맥용입니다.
- `ChiPDF-0.11.3-macOS-x86_64-LaMa.zip`: Intel 맥용입니다.
- `ChiPDF-0.11.3-Source.zip`: Windows·macOS 소스와 빌드 자료입니다. 테스트·QA 파일은 제외했습니다.
- `SHA256SUMS.txt`, `SHA256SUMS-macOS.txt`: 플랫폼별 배포 파일의 SHA256 목록입니다.

모든 배포본은 LaMa 모델과 CPU 실행 모듈을 포함합니다. 별도의 M2M100 오프라인 번역 모델은 포함하지 않습니다. 복원 방식에서 **주변색 보간** 또는 **사진 복원 · LaMa**를 선택할 수 있습니다.

맥에서는 ` → 이 Mac에 관하여`에서 칩 종류를 확인한 뒤 맞는 ZIP을 받으세요. 압축을 푼 `ChiPDF.app`을 응용 프로그램 폴더로 옮겨 실행합니다. Windows와 같은 `.twproj` 작업 파일을 사용하며, 운영체제에 없는 글꼴은 대체될 수 있습니다.

**맥 앱은 Apple 배포 서명·공증을 받지 않았습니다.** 임시 서명(ad-hoc)만 적용되어 macOS에서 실행 확인을 요구하거나 차단할 수 있습니다.
