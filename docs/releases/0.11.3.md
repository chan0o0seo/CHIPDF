# 치pdf 0.11.3

글자 크기 조절 화살표와 최근 작업 불러오기를 개선하고, LaMa 사진 복원 관련 소스·테스트·라이선스를 함께 관리하는 버전입니다.

## 변경 사항

- 글자 크기 등 숫자 입력칸의 위·아래 화살표를 테마에 맞는 아이콘으로 표시합니다. 값과 단위가 잘리지 않도록 입력칸 폭도 조정했습니다.
- 파일 메뉴의 **최근 작업 열기**와 시작 화면의 **최근 편집한 작업** 목록에서 원하는 파일을 불러올 수 있습니다.
- 최근 작업은 자동 저장본을 포함해 최대 12개를 기억합니다. 이름과 경로를 함께 표시하고, 삭제되거나 이동한 파일은 비활성화합니다.
- 이전 버전의 마지막 작업 기록을 이어받습니다. 자동 저장본을 별도 작업 파일로 저장하면 목록도 해당 파일로 갱신합니다.
- 작은 창에서는 시작 화면을 스크롤할 수 있습니다.
- 복원 방식의 **이전 방식**을 **주변색 보간**으로 이름을 바꿨습니다.
- 글자색 기반 브러시 선택, Alt+클릭 색 추출, Shift+드래그 선택 빼기, 지울 부분 미리보기와 LaMa 복원을 포함합니다.
- 작업 파일 형식은 **10**으로 유지합니다.

## 설치 및 실행

- `ChiPDF-0.11.3-LaMa-Setup.exe`: Windows 설치 파일입니다.
- `ChiPDF-0.11.3-LaMa-Windows.zip`: 모두 압축을 푼 뒤 `Translation Studio/Translation Studio.exe`를 실행하세요.
- `SHA256SUMS.txt`: 배포 파일의 SHA256 목록입니다.

두 배포본 모두 LaMa 모델과 CPU 실행 모듈을 포함합니다. 별도의 M2M100 오프라인 번역 모델은 포함하지 않습니다. 복원 방식에서 **주변색 보간** 또는 **사진 복원 · LaMa**를 선택할 수 있습니다.

## 검증 범위

- 최근 작업 기록·불러오기·기존 기록 호환, 화살표 클릭·실행 취소, 편집·저장·복구와 글자색 마스크·LaMa 가짜 실행 세션 테스트 **22개를 통과**했습니다.
- 패키징한 실행 파일과 Windows 파일 속성의 **0.11.3** 버전, 자료 열기·내보내기, 시작 화면의 최근 작업 표시를 별도 시험 데이터로 확인했습니다.
- 전체 회귀 테스트의 완전 통과를 의미하지 않습니다. 앞선 확장 실행에서 번역·브러시 작업 대기 시간 초과, 구버전 형식 기대값, 테스트용 폰트 누락으로 6개 실패가 확인됐습니다.
- 설치 프로그램을 통한 실제 설치·업데이트와 다양한 사진의 복원 품질 비교는 이번 검증 범위에 포함하지 않습니다.

소스와 아이콘, 테스트, 빌드 스크립트, 라이선스는 `ver_0.11.3` 태그에서 확인할 수 있습니다. 배포 파일과 모델·개인 작업 데이터는 소스 Git 이력에 포함하지 않습니다.
