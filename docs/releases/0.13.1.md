# 치pdf 0.13.1

원본 유지 출력의 경계선 문제와 이미지 출력 페이지의 용량을 개선한 Windows 업데이트입니다.

## 다운로드

| 운영체제 | 파일 | 지원 환경 |
| --- | --- | --- |
| Windows | [chipdf-0.13.1.exe](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.13.1/chipdf-0.13.1.exe) | Windows 10 1809 이상·Windows 11, x64 |

macOS는 [0.13.0](0.13.0.md)을 계속 사용합니다. 일본어 OCR 자료와 LaMa 사진 복원 모델·실행 모듈을 포함하며 Python이나 모델을 따로 설치할 필요가 없습니다.

## 변경 사항

- **수정 영역 경계선:** 원문 지우기 영역을 덮을 때 그 안의 바뀌지 않은 원본 선까지 이미지로 다시 그려, PDF 뷰어가 이미지를 확대·축소할 때 원본 벡터 선 옆에 가는 회색 선이 겹쳐 보였습니다. 이제 원본과 같은 픽셀은 원본 PDF를 그대로 보여 주고, 지운 글자 가장자리만 2픽셀 여유를 두고 덮습니다.
- **맞닿은 수정 영역:** 512픽셀 단위로 나누던 수정 이미지를 맞닿은 영역끼리 한 장으로 묶습니다. 떨어진 수정은 지금처럼 따로 덧입힙니다.
- **이미지 출력 용량:** 원본 PDF가 없는 페이지를 이미지로 출력할 때 사진이 많은 페이지는 JPEG(품질 92)로, PNG가 더 작은 페이지는 무손실로 저장합니다. 이미지 데이터를 25% 키우던 ASCII85 인코딩도 사용하지 않습니다. 실제 작업에서 이미지형 17쪽 자료가 72.7MB에서 18.1MB로 줄었습니다.
- **자동화 결과:** `export` 결과 JSON에 이미지로 출력한 페이지 번호(`raster_pages`), 출력 용량(`pdf_bytes`), 원본 대비 용량(`size_ratio`)과 경고를 표시합니다.
- **Codex 번역 스킬:** 작업 파일의 원본 PDF 연결(`pdf_asset`·`pdf_page`)을 지우지 않고, 배경 복원·그림 교체는 페이지 PNG 대신 배경 지우기 기록이나 이미지 상자로 넣도록 규칙을 추가했습니다.

이미 원본 PDF 연결이 빠진 작업은 다시 출력해도 페이지 이미지로 출력됩니다. 편집기의 **PDF 원래 배경 적용**에서 원본 PDF를 선택하면 원본 유지 출력으로 돌아갑니다. 작업 파일 형식은 0.13.0과 같습니다(버전 12).

## Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-0.13.1.exe`를 실행합니다.
2. 설치 안내를 따릅니다. 이미 설치했다면 기존 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다.
4. 스킬도 업데이트하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다.

기존 작업 파일, 자동 저장·백업, 개인 서식과 이미 설치된 오프라인 모델은 유지합니다.
