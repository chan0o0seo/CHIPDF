# 치pdf 0.13.0

PDF 전체를 이미지로 바꿔 출력하면서 용량이 커지던 문제를 개선했습니다. 새로 가져온 PDF는 원본 페이지를 유지하고 수정한 영역만 덧입힙니다.

## 다운로드

| 운영체제 | 파일 | 지원 환경 |
| --- | --- | --- |
| Windows | [chipdf-0.13.0.exe](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.13.0/chipdf-0.13.0.exe) | Windows 10 1809 이상·Windows 11, x64 |
| macOS | [chipdf-0.13.0.zip](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.13.0/chipdf-0.13.0.zip) | macOS 15 이상, Apple Silicon·Intel |

두 배포본 모두 일본어 OCR 자료와 LaMa 사진 복원 모델·실행 모듈을 포함합니다. Python이나 모델을 따로 설치할 필요가 없습니다. 기본 번역 엔진은 Chrome 내장 번역입니다.

## 변경 사항

- 원본 글자·벡터·압축 이미지를 유지합니다. 번역문, 삽입 이미지·도형, 원문 지우기·배경 복원은 투명한 수정 영역으로 추가합니다.
- 원본 PDF는 `.twproj`에 파일별로 한 번 보관합니다. 외부 원본을 옮겨도 이어서 작업하고 출력할 수 있습니다.
- 회전된 페이지와 잘린 페이지, 그룹·회전·투명도, 페이지 순서 변경과 일부 페이지 출력, 내부 링크를 지원합니다.
- 기존 작업은 계속 열 수 있으며, 원본이 없는 페이지는 종전처럼 이미지로 출력합니다. **PDF 원래 배경 적용**에서 원본 PDF를 선택하면 유일하게 일치하는 페이지에 원본도 연결합니다.

수정 영역을 덧입히므로 가려진 원문 텍스트가 PDF 내부에 남아 검색·복사에 포함될 수 있습니다. 번역문 자체는 이미지이며 검색·복사용 텍스트 레이어는 추가하지 않습니다. 원본의 주석·양식·책갈피·외부 링크는 복사하지 않으며 내부 페이지 링크는 작업 정보로 재구성합니다.

이 개선은 출력 PDF의 용량 증가를 줄입니다. `.twproj`에는 원본 PDF 외에도 편집용 페이지 이미지·배경 복원 자료를 보관합니다. 보관한 원본을 포함한 자산 한도는 512MB입니다. 새 작업 파일 형식(버전 12)은 0.13.0 이상에서 열어 주세요. 이전 버전의 작업 파일은 불러올 수 있습니다.

시험 문서에서는 같은 수정 결과의 PDF가 기존 약 2.20MB에서 약 0.28MB로 줄었습니다. 문서와 수정 범위에 따라 감소 폭은 다릅니다. Windows 소스와 배포본에 포함된 코드로 각각 36개 테스트를 통과했으며 실제 배포 실행 파일의 PDF 출력과 시각 비교도 확인했습니다.

## Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-0.13.0.exe`를 실행합니다.
2. 설치 안내를 따릅니다. 이미 설치했다면 기존 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다.
4. 스킬도 업데이트하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다.

기존 작업 파일, 자동 저장·백업, 개인 서식과 이미 설치된 오프라인 모델은 유지합니다.

## macOS 설치

1. `chipdf-0.13.0.zip`의 압축을 모두 풉니다.
2. ** → 이 Mac에 관하여**에서 칩/프로세서를 확인합니다.
3. M 시리즈이면 `Apple-Silicon`, Intel이면 `Intel` 폴더를 엽니다.
4. 해당 폴더의 `ChiPDF.app`을 **응용 프로그램** 폴더로 옮기고 실행합니다.

ZIP 안의 `설치 안내.txt`에도 안내가 있습니다. 맥 앱은 Apple 배포 서명·공증을 받지 않았습니다. 신뢰하는 배포본이 차단된다면 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 실행을 확인합니다.

Windows와 macOS 사이에 없는 글꼴은 대체될 수 있으므로 줄바꿈과 배치를 확인하세요. 자세한 기능은 [README](https://github.com/chan0o0seo/CHIPDF#readme), 소스는 [0.13.0 소스](https://github.com/chan0o0seo/CHIPDF/tree/ver_0.13.0)를 참고하세요.
