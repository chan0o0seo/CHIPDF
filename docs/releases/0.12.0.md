# 치pdf 0.12.0

PDF와 이미지 속 일본어를 읽고 한국어로 번역·편집하는 Windows·macOS 데스크톱 프로그램입니다. 이번 버전은 시작 화면의 파일 끌어 놓기를 고치고, Codex 번역 자동화와 플랫폼별 설치 안내를 함께 제공합니다.

## 다운로드

아래 두 파일 중 운영체제에 맞는 파일을 받으세요.

| 운영체제 | 파일 | 지원 환경 |
| --- | --- | --- |
| Windows | [chipdf-0.12.0.exe](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.12.0/chipdf-0.12.0.exe) | Windows 10 1809 이상·Windows 11, x64 |
| macOS | [chipdf-0.12.0.zip](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_0.12.0/chipdf-0.12.0.zip) | macOS 15 이상, Apple Silicon·Intel |

두 배포본 모두 일본어 OCR 자료와 LaMa 사진 복원 모델·실행 모듈을 포함합니다. Python이나 모델을 따로 설치할 필요가 없습니다. 기본 번역 엔진은 Chrome 내장 번역이며, Google Chrome 설치와 첫 언어팩 준비에는 인터넷이 필요합니다. 별도의 M2M100 오프라인 번역 모델은 포함하지 않습니다.

## Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-0.12.0.exe`를 실행합니다.
2. 설치 안내를 따릅니다. 이미 설치했다면 기존 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다. 바탕 화면 바로 가기는 설치 화면에서 선택할 수 있습니다.
4. Codex 번역 자동화도 사용하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다. 일반 편집기만 사용할 때는 해제해도 됩니다.

기존 작업 파일, 자동 저장·백업, 개인 서식과 이미 설치된 오프라인 모델은 유지합니다. 설치는 현재 사용자 계정에 적용합니다.

## macOS 설치

1. `chipdf-0.12.0.zip`의 압축을 모두 풉니다.
2. ** → 이 Mac에 관하여**에서 칩/프로세서를 확인합니다.
3. M 시리즈이면 `Apple-Silicon`, Intel이면 `Intel` 폴더를 엽니다.
4. 해당 폴더의 `ChiPDF.app`을 **응용 프로그램** 폴더로 옮기고 실행합니다.

ZIP 안의 `설치 안내.txt`에도 안내가 있습니다. 맥 앱은 Apple 배포 서명·공증을 받지 않았습니다. 신뢰하는 배포본이 차단된다면 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 실행을 확인합니다. [Apple의 실행 안내](https://support.apple.com/102445)를 참고하세요.

Windows와 같은 `.twproj` 작업 파일을 사용합니다. 운영체제에 없는 글꼴은 대체될 수 있으므로 줄바꿈과 배치를 확인하세요.

## 주요 기능과 사용 순서

1. **자료 열기** — 시작 화면·편집 화면에 PDF·PNG/JPG/JPEG/BMP 이미지를 끌어 놓거나 **파일 → 열기**를 선택합니다. 이미지·PDF 여러 개, 이미지 폴더 하나 또는 `.twproj` 작업 파일 하나를 열 수 있습니다.
2. **원문 인식·번역** — 문장을 사각형으로 선택해 일본어를 읽습니다. 가로·세로 원문을 지원하며, 한국어를 직접 입력하거나 **번역**을 누릅니다. Chrome 번역 도우미가 열리면 **번역 준비**를 눌러 연결합니다.
3. **원문 지우기·배경 복원** — 문장 영역이나 브러시로 원문을 지웁니다. **주변색 보간**과 **사진 복원 · LaMa**를 선택할 수 있고, 도장 도구로 주변 배경을 복제할 수 있습니다.
4. **글자와 배치 편집** — 글꼴·크기·색·부분 강조·정렬·문단 간격·한국어 세로쓰기를 조절합니다. 이미지·도형 추가, 회전·자르기·그룹·순서·잠금도 지원합니다.
5. **여러 페이지·링크** — 페이지별로 편집하고, 원본 PDF의 내부 페이지 링크를 유지하거나 텍스트 상자에 이동할 페이지를 지정합니다.
6. **저장·출력** — **작업 저장**으로 편집 가능한 `.twproj`를 보관하고 **내보내기**로 전체·현재·선택한 페이지를 PDF·PNG로 저장합니다. 자동 저장과 최대 12개의 최근 작업 목록으로 이어서 편집할 수 있습니다.
7. **Codex 번역 자동화** — 포함된 `chipdf-ja-ko` 스킬로 일본어 PDF와 코코포리아 룸 ZIP을 한국어로 작업합니다. `prepare`, `apply`, `preview`, `export` 명령과 편집본 열기를 지원합니다.

번역문은 원문과 대조하고 페이지 배치를 확인한 뒤 출력하세요. 작업 파일 형식은 10이며, 이전 형식 1~9를 읽습니다. 새로 저장한 형식 10 파일은 오래된 실행 파일에서 열리지 않을 수 있습니다.

## 0.12.0 변경 사항

- 시작 화면에 파일 드롭 처리가 연결되지 않던 문제를 수정했습니다. 최근 작업 목록·페이지 목록·캔버스에서도 자료를 끌어 놓아 엽니다.
- 드래그 진입·이동·드롭에 같은 파일 검사 기준을 적용합니다. 지원하지 않는 파일과 가져오기 중의 추가 드롭은 받지 않습니다.
- 맑은 고딕을 사용하는 일부 한글에서 획이 빠져 보이는 표시를 개선했습니다.
- 파일 기반 `--agent` 자동화와 Codex 번역 스킬을 배포본에 포함하고 Windows 설치에 스킬 선택 항목을 추가했습니다.
- macOS ZIP 하나에 Apple Silicon·Intel용 앱과 설치 안내를 함께 담았습니다.

자세한 기능 안내는 [README](https://github.com/chan0o0seo/CHIPDF#readme), 소스와 빌드 자료는 [0.12.0 소스](https://github.com/chan0o0seo/CHIPDF/tree/ver_0.12.0)를 참고하세요.
