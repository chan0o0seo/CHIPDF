# 치pdf 1.0.0

원본 배경을 그대로 보존하면서 일본어 원문을 한국어로 바꾸는 PDF 출력을 새로 만들었습니다. 번역한 원문이 PDF 텍스트이면 그 텍스트를 지우고, 그림 속 글자이면 배경에서 지운 자리만 이미지로 덧입힌 뒤, 한국어를 실제 글자로 넣습니다.

## 다운로드

| 운영체제 | 파일 | 지원 환경 |
| --- | --- | --- |
| Windows | [chipdf-1.0.0.exe](https://github.com/chan0o0seo/CHIPDF/releases/download/ver_1.0.0/chipdf-1.0.0.exe) | Windows 10 1809 이상·Windows 11, x64 |

macOS는 [0.13.0](0.13.0.md)을 계속 사용합니다. 일본어 OCR 자료와 LaMa 사진 복원 모델·실행 모듈을 포함하며 Python이나 모델을 따로 설치할 필요가 없습니다.

## 변경 사항

- **원문 종류별 처리:** 지운 영역 아래의 PDF 텍스트는 글자의 대부분을 지운 경우 PDF에서 실제로 삭제합니다. 배경은 원본 그대로이므로 복원 이미지가 필요 없습니다. 그림 속 글자처럼 텍스트 삭제로 설명되지 않는 복원·삽입 부분만 작은 이미지로 덧입힙니다.
- **한국어 실제 글자:** 번역문을 글꼴(사용한 글자만 포함)과 함께 PDF 글자로 저장합니다. 확대해도 선명하고 검색·복사할 수 있습니다. 도형·삽입 이미지·회전·투명도·세로쓰기는 편집 화면과 같은 방식으로 그립니다.
- **자동 확인:** 저장한 페이지를 편집 화면과 비교해, 글꼴이 없거나 줄바꿈이 달라져 다르게 보이는 페이지는 글자를 이미지로 넣습니다.
- **선택 가능:** PDF 저장 창의 **한국어 글자**에서 **글자로 넣기**(기본)와 **이미지로 넣기**(0.13 방식)를 고릅니다. 자동화 `export`는 `--text-mode text|image`를 받습니다.
- **자동화 결과:** `export` 결과 JSON에 `text_mode`, 글자를 이미지로 넣은 페이지(`image_text_pages`), 지운 원문 텍스트 수(`removed_source_text`)를 추가했습니다.
- **위치 기준 원본 연결:** **PDF 원래 배경 적용**에서 픽셀이 일치하는 페이지를 찾지 못한 경우, 선택한 PDF 하나가 작업과 페이지 수가 같고 페이지마다 가로세로 비율이 같으면 같은 순서의 원본 페이지에 연결합니다. 배경을 다시 만들거나 그림을 붙여 넣은 작업도 원본 유지 출력을 쓸 수 있습니다. 배경과 지우기 자료는 바꾸지 않고, 인쇄 크기만 원본에 맞춥니다. 이미 연결된 페이지가 다른 순서이면 위치로 연결하지 않습니다.
- **배경 비교 개선:** 지운 영역 밖에서 원본을 다시 샘플링한 정도의 차이는 원본을 그대로 보여 주고, 실제로 바뀐 그림·옮긴 요소만 이미지로 덧입힙니다. 원본 선 옆에 복사본 선이 겹쳐 보이지 않습니다.

## 디자인 편집

- **글자 효과:** 외곽선(색·두께), 그림자(색·진하기·거리·방향·흐림), 글자 배경색, 자간을 넣었습니다. 가로쓰기와 세로쓰기 모두 적용되며, PDF로 저장해도 한국어는 실제 글자로 유지됩니다. 흐린 그림자만 작은 이미지로 들어갑니다.
- **투명도:** 텍스트 상자의 글자와 상자 배경 투명도를 따로 조절합니다. 대상 전체 불투명도도 그대로 쓸 수 있습니다.
- **그림 편집:** 밝기·대비·채도, 모서리 둥글게, 테두리 색·두께를 조절합니다. 원본 그림 자료는 바꾸지 않습니다.
- **캔버스 조작:** 선택한 대상에 조절점 8개와 회전 손잡이가 화면 배율과 관계없이 같은 크기로 보입니다. 어느 조절점을 끌어도 반대쪽이 제자리에 남고, 비율 고정 그림과 그룹은 모서리로만 조절합니다. 마우스를 올린 대상에 테두리가 보입니다.
- **서식 도구 막대:** 캔버스 위쪽에 고정되어 선택한 대상에 맞게 바뀝니다. 텍스트는 글꼴(미리보기)·크기 −/+·글자색·굵게·기울임·밑줄·취소선·정렬(누를 때마다 바뀜)·목록·간격(자간·줄 간격)·세로쓰기·투명도·효과·위치·서식 복사, 그림은 교체·자르기·뒤집기·비율 고정·조정·모양, 도형은 채우기·테두리·선 두께를 다룹니다. 복제·삭제·잠금·순서·그룹은 더보기(…) 메뉴에 있습니다. 서식 복사는 누른 뒤 다른 텍스트를 클릭하면 같은 서식이 적용됩니다.
- **목록:** 글머리표와 번호 목록을 넣었습니다. 가로쓰기 상자에서 쓸 수 있고, PDF에서도 실제 글자로 남습니다.
- **속성 패널:** 슬라이더는 끄는 동안 바로 미리 보여 주고 놓으면 실행 취소 한 번으로 묶입니다. 색 버튼은 문서에서 쓴 색·최근 색·기본 색·스포이트를 보여 줍니다. 위치·크기를 직접 입력하고, 정렬·간격·순서 버튼을 바로 누를 수 있습니다. 새 **레이어** 탭에서 대상을 끌어 앞뒤 순서를 바꿉니다.

실제 작업 3개를 다시 출력해 기존 완성본과 페이지별로 비교했습니다. 화면 차이는 가장 큰 페이지도 4배 축소 기준 0.4% 이하(글자·선 가장자리의 1픽셀 미만 차이)였습니다.

| 자료 | 원본 | 이전 완성본 | 1.0.0 |
| --- | --- | --- | --- |
| 오프닝 12쪽 (일본어가 PDF 텍스트) | 1.18MB | 27.7MB | 1.46MB |

| 이미지형 OP 17쪽 (그림 속 일본어) | 4.59MB | 72.7MB | 12.47MB |

## 알아 둘 점

- 글자로 넣기에서는 지운 원문이 PDF에서 삭제되므로, 이전처럼 가려진 일본어가 검색·복사되지 않습니다. 글자의 일부만 지운 원문은 남기고 화면과 같게 보이도록 이미지로 덮습니다.
- 출력에 쓸 글꼴이 PDF 포함을 허용해야 합니다. 허용하지 않거나 없는 글꼴을 쓴 페이지는 자동으로 이미지 글자로 저장됩니다.
- 원본 PDF가 연결되지 않은 페이지는 지금처럼 페이지 이미지로 출력됩니다. 기존 작업은 편집기의 **PDF 원래 배경 적용**으로 원본을 연결할 수 있습니다. 페이지 수나 비율이 다르고 픽셀도 일치하지 않는 페이지는 연결되지 않습니다.
- 작업 파일 형식이 13으로 바뀌었습니다. 1.0.0에서 저장한 작업 파일은 이전 버전에서 열 수 없으며, 이전 작업 파일은 그대로 열립니다.

## Windows 설치

1. 실행 중인 치pdf를 닫고 `chipdf-1.0.0.exe`를 실행합니다.
2. 설치 안내를 따릅니다. 이미 설치했다면 기존 폴더에 업데이트합니다.
3. 시작 메뉴의 **치pdf**를 실행합니다.
4. 스킬도 업데이트하려면 기본 선택된 **Codex 번역 스킬 설치**를 유지합니다.

기존 작업 파일, 자동 저장·백업, 개인 서식과 이미 설치된 오프라인 모델은 유지합니다.
