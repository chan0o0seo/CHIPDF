# 치pdf 0.12.1

- 페이지 목록에서 끌어서 순서를 변경할 수 있습니다. Ctrl/Shift로 여러 페이지를 선택한 뒤 함께 옮길 수 있습니다. 우클릭 메뉴에서는 한 페이지 앞뒤 또는 지정 위치로 옮깁니다. 변경은 실행 취소·다시 실행할 수 있으며 원본 이미지, 편집 내용과 내부 페이지 링크가 유지됩니다.
- 가로쓰기 텍스트 상자를 선택하고 오른쪽 서식 패널의 문단에서 위·세로 가운데·아래 정렬을 선택할 수 있습니다. 문단의 왼쪽·가운데·오른쪽 정렬과 함께 적용되며 저장과 PDF·PNG 출력에도 반영됩니다. 세로쓰기는 기존 문단 정렬을 사용합니다.
- 설치 시 제공되는 Codex 스킬은 작업 종료 후 완성본과 ChiPDF 편집본을 별도의 ZIP으로 묶어 전달합니다. 편집본에는 마지막 출력에 사용한 최종 `.twproj`를 담습니다. 코코포리아 룸 작업도 같은 기준을 적용합니다.

기존 작업 파일을 열 수 있습니다. 이 버전으로 저장한 작업 파일은 새 세로 정렬 정보를 포함하는 프로젝트 형식 11을 사용하므로 치pdf 0.12.1 이상에서 열어 주세요.
